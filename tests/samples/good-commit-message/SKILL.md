# 커밋 메시지 작성

1. `git diff --staged` 로 바뀐 내용을 본다.
2. 첫 줄은 50자 안쪽으로, 무엇을 왜 바꿨는지 쓴다.
3. 빈 줄 다음에 자세한 설명을 쓴다.
4. 초안을 사용자에게 보여 주고, 사용자가 고친 뒤 직접 커밋하게 한다.

## 예시

```
로그인 실패 메시지를 한국어로 바꿈

영어 오류 문장이 그대로 보여서 사용자가 이해하기 어려웠다.
```

가족 이모지도 문제없이 쓸 수 있다: 👨‍👩‍👧
